# Pwnagotchi_Pager
A pwnagotchi for the Hak5 WiFi Pineapple Pager. Hunts WPA handshakes and PMKIDs on its own, aims deauth at individual clients rather than broadcasting, skips networks where it cannot work, and stops the moment it has what it needs. Adapts to signal, density and movement, with or without an MK7AC.
